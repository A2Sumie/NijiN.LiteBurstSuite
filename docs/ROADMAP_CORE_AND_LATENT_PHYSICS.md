## 一、物理硬天花板与六大传感器家族统一矩阵

### 1.1 四条硬物理边界

1. **像素孔径方块积分 $\text{sinc}$ 零点**：
   无隙微透镜在像元宽度 $p$ 上的积分传递函数为 $\text{MTF}_{\text{pixel}}(f) = |\text{sinc}(p f)|$，在 `1.0×` 奈奎斯特（$f = \frac{1}{2p}$）处为 $63.7\%$，`1.5×` 处为 $30.0\%$，**在 `2.0×`（$f = \frac{1}{p}$）处精确归零（$0\%$）**。零先验线性逆问题的可恢复空间频率上限收敛于 **`1.80× ~ 1.88×`**（相比单帧拜耳/X-Trans 无伪色安全极限 `0.60× ~ 0.65×`，真实无混叠线性解析力提升约 **`2.8 倍`**）。

2. **光圈衍射截止窗口 $f_c = \frac{1}{\lambda F}$（$\lambda = 0.55\text{ }\mu\text{m}$）**：
   全画幅 45MP（$p=4.35\text{ }\mu\text{m}, f_{N,2\times}=230\text{ lp/mm}$）真 `2×` 超分黄金光圈为 `f/2.0–f/5.6`；全画幅 24MP（$p=5.94\text{ }\mu\text{m}, f_{N,2\times}=168\text{ lp/mm}$）至 `f/8`（$f_c=227\text{ lp/mm}$）仍在甜点内；APS-C 40MP（$p=3.04\text{ }\mu\text{m}, f_{N,2\times}=329\text{ lp/mm}$）真超分集中在 `f/1.4–f/4.0`，更小光圈下自动收敛反卷积强度，转向消伪色/消蠕虫与动态范围增益。

3. **手持微抖动解耦硅片本底误差（Dithered Stacking & In-Burst Dark Subtraction）**：
   同曝光 $N$ 帧叠加拓展 `0.5 log2(N)` 档暗部动态范围；手持 `>= 4 px` 自然漂移令传感器死坐标 $(r_{\text{raw}}, c_{\text{raw}})$ 与世界景物坐标 $(x, y)$ 完全正交，不仅将固定模式噪声（FPN / PRNU）与有损 RAW（如 Nikon `HE*`）块量化误差打散为按 $1/\sqrt{N}$ 衰减的白噪声，还允许**直接从亮帧连拍残差中实时反演出当前温度态下的硅片行/列读出条纹与温点黑场并精确扣除**。

4. **全画幅/中画幅显存硬约束（Tiled VRAM + Compact `fp16` Global Canvas）**：
   `183 MP ~ 408 MP` 重建若将 IBP、半栈、BM3D 等多组中间张量整幅常驻显存，峰值将突破 `10–16 GB`。引擎强制采用 **`2048×2048`（含 `64 px` 重叠裙边）GPU 流式瓦片工作集 + 主机/统一内存 `fp16` 全幅汇总画布**：GPU 瓦片工作显存严格封顶在 **`< 600 MB`**（核显至独显通吃 4 亿像素中画幅），同时通过 `fp16` 全幅画布（1.83 亿像素仅 `1.1 GB`）保障 Stage 6 全局分位数自动曝光与分条编码**跨瓦片 100% 零接缝**。

## 二、核心重建引擎：`C0–C13` 全模块规格（按 Stage 0 → Stage 6 数据流编排）

- **`[C0] 双模态流式瓦片异构底座（GPU `2048²` VRAM Tile / CPU `256²` L2-Cache Micro-Tile + `fp16` 无缝画布）`**：
  严格兼顾 GPU 与纯 CPU（`ARM64 NEON` / `x86_64 AVX2`）双端高速同构执行：
  - **GPU 端（`Metal` / `Vulkan`）**：采用 `2048×2048`（`+64 px` halo）瓦片流式调度，GPU 工作集 `< 600 MB`；
  - **纯 CPU 端（`NEON` / `AVX2` 多核无锁并行）**：自动切换为每工作线程独占的 **`256×256`（`+32 px` halo）微瓦片**，单线程工作集仅 `~1.5 MB`，**100% 驻留单核高速 L2/L3 Cache 内部免落内存条**，在单块缓存生命周期内串联完成「初值核聚合 → IBP 回投 → 半栈互谱/`BM3D-Lite` → 分型 RL」；
  - 双端输出统一汇入紧凑 `fp16` 全幅画布（`183 MP` 仅 `1.1 GB`，总内存峰值 `<= 2.0 GB`）供 Stage 6 全局分位数影调与分条编码，跨瓦片 100% 零接缝且 CPU/GPU 输出保持 `PSNR > 80 dB` 一致。

### Stage 0：EXIF 物理遥测、对焦点锚定与高速跳帧选相
- **`[C12a] 原厂 EXIF / MakerNotes 遥测引导`**：
  读取 `LibRaw` 已解析的：① **防抖标志** `ImageStabilization / VibrationReduction`（区分 IBIS 传感器平移与 OIS 浮动镜组偏心）；② **快门类型** `ShutterType`（机械快门锁定果冻为 0 并查首帧震动；纯电子快门按堆栈等级启用 `C10`）；③ **真实对焦点框** `FocusLocation / AFPointSelected`（**主体局部锐度选片与定格**：多动体场景优先按对焦点框内的局部锐度选举皇冠锚定帧，而非被背景树林锐度带偏！）；④ **硬件连拍组号与硅片温度**（如尼康 `BurstTable_0x0056_gid`、`ExposureBracketValue`、`SensorTemperature`）。
- **`[C8] 高速连拍四象限最大熵跳帧选相器`**：
  针对 `30–120 fps`（帧间隔 `8.3–33 ms` 短于人手 `8–12 Hz` 生理震颤周期）的候选池，基于粗配准亚像素相位贪心遴选均匀覆盖 `(0,0),(0,1),(1,0),(1,1)` 四象限且对焦点最锐的 `8–12` 张黄金子集。

### Stage 1 & 2：统一 `cfa6x6` 解包、实时硅片本底自扣除与曝光对齐
- **`[C11a] 统一 `cfa6x6` 解包与高光保护偏移还原`**：
  利用 $\text{lcm}(2,6)=6$，以 36 字节常量相位表 `cfa6x6[6][6] ∈ {R,G,B}` 统一承载全部 `2×2` Bayer 与 `6×6` X-Trans，解析 `6×6` 暗电平偏置与富士 `DR200/DR400`（`RawExposureBias`）欠曝保护增益。
- **`[C13] 亮帧内实时硅片本底与行列条带自扣除（In-Burst Silicon Dark & Banding Self-Subtraction）`**：
  在手持微移 $\ge 4\text{ px}$ 的序列中，将对齐后的静态场景估计逆投影回每帧相减，**仅在暗部平坦门控像素（`<15%` 满阱且 $|\nabla X| < 2\sigma$）** 上于原始传感器坐标 $(r_{\text{raw}}, c_{\text{raw}})$ 求跨帧温点中位数及行/列残差中位数，并对行/列偏置施加 **一维正交轴高通滤波（$\sigma_{\text{hp}} = 16\text{ px}$，防止天际线或渐晕低频泄漏产生假条带）** 后从源帧精确扣除。
- **`[C7] 不等曝光连拍（AEB）泊松方差最优融合`**：按实测线性通量比对齐包围曝光帧，以非饱和区泊松-高斯方差倒数最优加权合成 `18+ EV` 超分底片。

### Stage 3：行样条抗果冻、稠密微视差与 OIS 浮动光轴色差配准
- **无空绿半尺寸复用（`[C11b]`）**：依托 X-Trans 任意 `2×2` 窗口必含 `2–3` 个绿像素的几何性质，零改动复用整套 `(H1/2 × W1/2)` 配准与场图骨架。
- **`[C10] 非堆栈电子快门一维行带果冻样条`**：对慢读出静音快门叠加按行带一维平滑样条 $\delta\mathbf{u}(r)$ 消除手震果冻水波纹（机械快门与 A9 III 全域快门自动旁路）。
- **金字塔顶层稠密 IC-LK 光流微调**：吸收连续景深斜坡微视差，减少误触发去鬼影退回单帧的面积。
- **`[C5a & C12b] 盲二维倍率色差（2D LCA）+ OIS 逐帧微漂移补偿`**：在参考帧边缘盲拟合静态二维色差场 $\mathbf{\Delta}_{R/B}(x,y)$；当开启镜头 OIS/VR 时追加每帧 4 参数全局色差微平移项 $\delta\mathbf{\Delta}_{R/B,n}$，吸收浮动防抖镜组偏轴引起的色边漂移。

### Stage 4：遮挡双层剥离、正交幸运去抖、跨通道色线与 IBP 回投
- **`[C4] 近景遮挡边缘双层剥离补全（Disocclusion Unpeeling）`**：在极线视差显著的前后景交界建立 $I_n = \alpha_n L_{\text{fg}} + (1-\alpha_n)L_{\text{bg}}$，用绕过前景显露背景的邻帧补齐轮廓外侧背景真超分。
- **`[C3] 零 FFT 空域四方向幸运择优（Spatial 4-Orientation Lucky Weighting）`**：摒弃昂贵的全图复数 FFT，直接在半尺寸金字塔上以 4 组 `3×3` 方向二阶导数核（$0^\circ, 45^\circ, 90^\circ, 135^\circ$，纯 SIMD 加减移位，CPU 全幅耗时 `< 40 ms`）评估各帧局部方向锐度，动态调制每帧椭圆核方向权重（全序列同向匀速拖影则诚实保留自然过渡）。
- **`[C11c] 统一 `cfa6x6` 核与 X-Trans `6×6` 色差采集窗`**：X-Trans 下 `R/B` 残差窗口扩至 `6×6` `1×` 像素，配一阶梯度单帧动体兜底，从物理采样根源消灭“富士蠕虫”。
- **`[C2] 跨通道色线联合超分`**：在低色差梯度边缘将同帧 `R/B` 二阶高频差分并入亮度方程，提升 `2–4` 帧少帧抗锯齿力。
- **`[C1] 紧支集 1–2 步加速残差回投（Compact-Support Nesterov IBP）`**：在瓦片缓存内对原始传感器采样点执行默认 `1` 步（极致档 `2` 步，`3×3` `1×` 紧支集）重投影残差回投，以约 `+25%` 轻量算力消除超过 `80%` 的不均匀象限混叠误差。

### Stage 5：CPU/GPU 双端轻量化集平均半栈互谱维纳、核预白化、瓦片共享 KLT 与分型 PSF 反演
- **`[C6a] 分尺度集平均奇偶半栈互谱维纳（Scale-Split Ensemble Cross-Spectral Wiener）`**：
  - **严格启用域**：仅在 $N_{\text{eff}}(x,y) \ge 5$ 且奇偶半栈 $(Y_A, Y_B)$ 相位均衡的超定静态区启用（少帧与动体区平滑回退至逐像素 $\eta(x,y)$ 解析方差）；
  - **CPU/GPU 同速集平均机制**：在 `L0` 全分辨率层（`stride = 4`）直接对局部 `3×3` 邻近变换块（$M=9$ 块连续内存，零搜索开销）做差谱 $\frac{1}{4}|C_A - C_B|^2$ 与互谱 $\text{Re}(C_A \overline{C_B})$ 集平均；非局部相似块搜索严格下沉至像素量少 4–16 倍的 `L1 / L2` 层。
- **`[C6b] 结构张量核协方差预白化`**：按 Stage 4 已知椭圆核传递谱 $H_{\text{kern}}^2(u,v;\theta,\sigma_\parallel,\sigma_\perp)$ 对变换域噪声谱做精确逆白化，消除顺边缘细长有色噪纹与中频结块麻点。
- **`[C6c] 瓦片共享 `3×3` 色空 KLT + `L1/L2` SIMD `BM3D-Lite`（Hadamard-8）`**：
  - **零分支瓦片 KLT**：每 `64×64` 区域共享一组信噪比白化后的 `3×3` 自适应色彩主成分正交基（全幅仅需数万次极速 `3×3` 特征分解，CPU 耗时 `< 3 ms`），瓦片内纯矩阵乘流式执行，根除细小红字与星点串色掉色；
  - **CPU 友好的 `L1/L2` `BM3D-Lite`**：仅在 `L1/L2` 金字塔层用 `2×2` 块均值（16 维特征 = 2 条 `AVX2` / 4 条 `NEON` FMA 指令）在 `25` 个步长点内快筛 Top-8 相似块，第三维采用纯加减零乘法的 `1D Walsh-Hadamard-8` 正逆变换，使 8 核 CPU 在 `183 MP` 下亦可在数秒内跑完。
- **`[C5b & C9] 分型 OLPF / 空间可变椭圆 PSF 反卷积`**：无低通机采用中心/四角自适应椭圆核（小像元高 $F$ 值按衍射自动收敛）；四点弱 OLPF 机采用四点分裂核 $K_{4\text{-spot}}(d)*G_\sigma$（余弦零点前截止）；EOS R1 `GD-LPF` 采用匹配复合高斯核。

### Stage 6：双模式 DNG（兼顾 Lightroom 与 Capture One）及无损交付
- **`[C11d]` 富士 X-Trans 双模式 DNG 封装**：
  - 默认 `dng`（规范化 `2×2 RGGB` 16-bit `SOF3` 无损 DNG，`0.39×` 小体积）：零蠕虫，100% 兼容 **Lightroom / ACR 原厂富士胶片模拟 DCP** 与拜耳专用 AI 降噪；
  - 可选 `dng-linear`（3 通道 `Photometric=34892 LinearRaw` `SOF3` 无损 DNG）：专门保障 **Capture One** 富士原厂曲线识别与科研零子采样需求。

## 四、反过度乐观红队审查台账（被修正/降级的假设及严格物理理由）

| 审查项 | 早期过度乐观设想 | 物理/数学失灵根因（定量理由） | 定稿修正方案 |
| :--- | :--- | :--- | :--- |
| **1. EXIF 陀螺仪直接减旋转** | 用 MakerNotes `Roll/Pitch/Yaw` 直接减去相机旋转分离平移视差 | 静态照片 EXIF 倾角分辨率仅 `~0.1°` 且每帧仅单次低频采样；在 85mm 镜头上 `0.1°` 量化误差高达 **`34 像素`**，远粗于亚像素需求。 | 仅用 EXIF 倾角判断地平线/重力方向；纯旋转单应 $H_n$ 100% 由图像特征自身亚像素拟合。 |
| **2. 原地短连拍出稠密真深度** | 任意原地手持连拍均能算出精细全图深度用于重对焦 | `30–120 fps` 短促连拍以手腕纯旋转为主，真实平移基线仅 `1–3 mm`；广角下中景视差 `< 1.5 px` 且与 IBIS 主点偏移、电子快门果冻共线耦合。 | 设立 **`Δd_max >= 8 px` 硬门禁**：原地微基线仅用于内部去鬼影分层；精细深度/2.5D/重对焦要求中长焦或引导用户横向微移 `2–5 cm`。 |
| **3. 中远景手晃测散焦前后焦符号** | 靠日常手持前后 `5 mm` 晃动区分前焦与后焦 | 纵向放大率 $M_L = (f/Z)^2$：50mm 镜头拍 3m 主体时 $M_L = 1/3600$，手晃 `5 mm` 弥散圆仅变 **`0.16 px`**，完全淹没于手震动糊与噪声中。 | 严格限定 `L2` 仅在 **微距近摄（$M > 1/20$）或对焦包围序列** 下启用；中远景远近顺序统一由 `L1` 视差决定。 |
| **4. 原地连拍消整扇展柜玻璃反光** | 普通原地手持 `1–2 cm` 即可剥离大面积窗户倒影 | 面积宽 `400 px` 的亮反光在移动 `5 px` 后仍有 `98%` 重叠（低频零空间退化），且叠加满阱截断破坏线性可加性。 | 原地连拍仅做**小尺度碎高光/水面鳞光下包络抑制**；大面积展柜消反光单独列为**引导式宽基线横移（`5–15 cm`）未过曝专项模式**。 |
| **5. 单频点裸用奇偶半栈互谱** | 单个 `8×8` 块单频点直接取 $\max(0,\text{Re}(C_A\overline{C_B}))$ | 单个频点仅 1 对样本，纯噪声下仍有 `50%` 概率为正（涨落达 $0.7\sigma^2$），且 `N=4` 时奇偶半栈异象限混叠反相会误杀真高频。 | 强制要求 **$N_{\text{eff}} \ge 5$ + `BM3D-Lite` 相似块集（$M \ge 8\text{–}16$ 块）统计集平均**，压低涨落方差 4 倍后再做维纳收缩。 |
| **6. 帧间位移插值算帧内动糊核** | 用前后帧位置差与电子快门剪切逆推曝光瞬间模糊核 | 当快门占空比低（如 `20fps` 配 `1/1000s`）或手震在曝光内回钩拐弯时，帧间位移与帧内轨迹无关；且全帧同向匀速拖影频域零点重合不可逆。 | 取消帧间轨迹外推猜核；`C3` 严格聚焦各帧抖动方向随机正交时的频域择优，同向集体拖影诚实保留自然过渡。 |
| **7. Capture One 直读改写 CFA 的富士 DNG** | 以为所有软件看到 `Model=X-T5` + `RGGB` 都能挂富士曲线 | Lightroom/ACR 按机型名匹配 DCP 完全正常；但 Capture One 原厂解析器校验富士机型与 X-Trans CFA 绑定关系，非 `LinearRaw` 可能退回通用曲线。 | 提供双模式：默认 `2×2 RGGB SOF3 DNG`（体积 `0.39×`，通吃 LR/ACR 胶片模拟与 AI 降噪）+ 可选 `3-ch LinearRaw DNG` 专供 Capture One 富士用户。 |
| **8. 全画幅整图常驻显存跑重算子** | 在整幅 `183 MP` 缓冲上串联 IBP + 半栈 + 多场图 | `183 MP` 单张 `RGB float32` 即占 `2.2 GB`，多缓冲叠加在 8–16GB 设备上必爆显存，且全算 10 张场图拖慢日常耗时。 | 确立 **`[C0]` `2048×2048` 流式瓦片底座（显存封顶 `<= 2 GB`）+ 扩展场图按需惰性求值**。 |
