# NOPB/1 与手持光学 Rev 2：第二轮冻结审查

**裁决：可以冻结 NIB/1 的 64/128 字节布局、双端点坐标公式和政策槽的分工。生产宿主与光学数字指标有条件通过。** 最优先的改动是把原生解码器接到 `open_session`：让任意调用方都能从 RAW 得到真实活动区、预览和可用算子。随后用一种普通的浮点保护掩膜，验收“外部坐标 → 宿主采样 → 实际改变正确位置的输出像素”整条路径。

审查对象：[Rev 2 主提案](V3_OPTICAL_LIMITS_AND_SIDECAR_ARCHITECTURE_ZH.md)、[对接指南](../sdk/README_ZH.md)、[C 头](../sdk/nib_v1.h)、[线编解码](../sdk/nib_wire.py)、[会话实现](../sdk/nijin_bus.py)、[互操作测试](../sdk/tests/test_interop.py)、[首轮结论](V3_OPTICS_SIDECAR_REVIEW_ZH.md)。本次运行仓库托管测试得到 **14 passed，0 skipped**，含 C++20 独立读者；提案首页的 13 是前一版计数。以下结果还使用了实拍 Nikon Z8、跨进程公共入口及独立的离散核计算。

### 2.1 能存一种数据，与宿主能按其含义采样，是两道验收

用 **4×1** 测试就能发现三个普通适配器会遇到的问题。底图各通道 0.2，替换图 0.8；保护规则为“掩膜值 1 保留底图”。以下是通过公开合成算子读回的红通道：

| 输入（其余相同） | 应得 | 现值 |
|---|---|---|
| U8 保护场 `[0,1,0,1]` | `[.8,.2,.8,.2]` | `[.8,.2,.8,.2]` |
| F32 保护场 `[0,1,0,1]` | `[.8,.2,.8,.2]` | **`[.8,.8,.8,.8]`**；四点的来源位也跟着改变 |
| 同尺寸 RLE：外格首点为 1，Chart 转 180° | 活动格末点受保护：`[.8,.8,.8,.2]` | **`[.2,.8,.8,.8]`** |

原因在[掩膜消费](../sdk/nijin_bus.py#L923)：普通掩膜以 `list(pm.read())` 拆**字节**，RLE 则直接使用解出的存储顺序。权重和 RGB 固定按 `<f` 解释；传入合法 F64 权重时，本轮还观测到样本数被翻倍、合成索引报错。这个问题适用于所有提供图层/选区的调用者，与字段来源无关。

**改一处即可服务多种工具：** 在端口绑定时解析成按元素访问的视图，校验 dtype、通道轴、frame/batch、色彩空间和曝光单位；然后按源 Chart、目标 Chart、有效支持域执行一次坐标转换。硬标签用最近邻，概率按声明规则，logit 要有阈值或校准。对尚无对应重采样器的端口，返回 `grid_mismatch` 或 `unsupported_dtype`。原生 CPU/GPU 与参考服务器使用同组小数组验收。

**分数有效域还有独立的半像元问题。** 当横向有效框为 `[0,2.4)`、像素中心为 `0.5,1.5,2.5` 时，活动点 `x=2.3` 由[当前夹紧函数](../sdk/nib_wire.py#L279)映到 **1.9**；双线性采样仍对有效域外的 `2.5` 中心给 **40%** 权重。若存储值为 `[1,1,0]`，读到 0.6。采用“中心落框内即有效”的约定时，先求离散中心索引

$$
i_{\min}=\lceil u_0-\tfrac12\rceil,\qquad i_{\max}=\lceil u_1-\tfrac12\rceil-1 .
$$

裁到数组后，仅在 $i_{\min}+1/2$ 与 $i_{\max}+1/2$ 之间采样；无有效中心的 `[0.8,1.2)` 返回 `missing`。若上游提供的是部分覆盖像元，就传有效权重，并对有效插值足迹重新归一。

**另外三个与接入成本直接相关的细节：**

* [RLE 适配器](../sdk/nijin_bus.py#L577)对 `counts="022"` 正确解出 `[1,1,0,0]`，同内容的 `b"022"` 却报游程和错误。常用 [COCO Python 编码器](https://github.com/cocodataset/cocoapi/blob/master/PythonAPI/pycocotools/_mask.pyx)实际返回 `bytes`。适配层统一 bytes/str 和整型 runs，再与独立编码器的非对称掩膜交叉检查。现有 C++ 测试读取的是 **RLE 与 RGB** 的字段片段；稀疏点表另用 C++ 读回完整坐标及对应帧才覆盖提案中的该项承诺。
* 给 `NCHW`、`T×M×K×H×W`、轨迹和 WarpGrid 建好描述符是有效进展。实际绑定政策时还要确定是哪一帧、对象和候选、曲线/核的单位，以及网格值是绝对端点还是偏移。对于不同调用者给出的同一物理场，比较**最终采样或重投影**比比较序列化的 shape 更有判别力。
* `put(..., origin=0)` 有客户端检查；[接收外部包的路径](../sdk/nijin_bus.py#L429)在接纳字段时沿用描述符来源。现有[测试](../sdk/tests/test_interop.py#L323)把底图在客户端构造后随补丁传给宿主。生产契约宜让外部政策**引用已有宿主测量的字段 ID**，宿主在 `attach` 校验允许写入的字段及来源；受信检查点恢复按独立语义读取。`computed_by_host` 与“该像素的信息来自哪份输入”分别记录，使对齐、测量和外部标定的数据都可追溯。

### 2.2 可重复调用与阶段状态

| 正常操作序列 | 实际表现 | 建议契约 |
|---|---|---|
| 已完成 S5，收到 S2 更新，仅调用 `mark_executed_through(S2)` | 由“仅 S1 有效”跳到 **S1–S5 全缓存、脏集合为空** | [状态更新](../sdk/nijin_bus.py#L416)应由实际完成的代际/阶段推进；此例重算后 S1、S2 有效，S3–S5 仍脏。发布输出后再推进状态。 |
| `call(..., adopt_outputs={"grad":"my.grad"})`，随后 `get_fields(["my.grad"])` | NLL 值与梯度正确；导回包中出现的名称却是 **`grad`** | 收编输出时同时重建短键、`public_name` 和目录映射；检验客户端能按原认领的名字再次调用算子。[当前赋值位置](../sdk/nijin_bus.py#L1021)。 |
| 在本地设置保护策略，`sync_to_host(names=["roi"])` | 掩膜到达，返回的 `policy` 为 **`{}`**；全量同步才携带策略 | 协议显式区分字段补丁与政策提交；若提交两者，携带政策所依赖字段/Chart 的闭包或有效引用。[当前保存条件](../sdk/nijin_bus.py#L716)。 |
| 已设置保护区和 `bokeh_de_nisen=1`，再调用 `set_optics_policy(bokeh_swirl=.3)` | 原保护区变 `None`，原平滑强度变 0 | 明确 `patch` 与 `replace`：局部修改保留其他键；整段替换显式调用。换用同名 Chart 也应使实际引用该 Chart 的消费者失效。 |

`get_fields` 和 `call` 现在会[生成各自的临时 `.nib`](../sdk/nijin_bus.py#L1120)。已写文件的 NumPy 读取是有效的 mmap；整个过程还包括宿主写文件、格式转换和输出组装。以 45.7 MP RGB32f 为例，一幅为 **548.4 MB**；[合成算子](../sdk/nijin_bus.py#L954)将两幅输入展开为 Python 浮点列表，在常见 64 位 CPython 上两份列表的元素和引用合计约 **8.8 GB**，还要加其他缓冲。生产实现采用宿主条带/ROI 或设备视图，区分 `file_mmap`、共享缓冲与设备句柄，记录每次会话的实际复制字节、峰值和释放时机。这样调用方可以按能力发现选择传输，不需要针对工具型号分支。

## 3. 三项光学 Oracle 的独立复算

### OP-O1｜差量保常色成立；正性、锐核和邻点间距需要各自的条件

**通过部分。** 固定谱合成列 $t_q$，空间算子满足 $K_q1=1$ 时，$c+\sum t_q(K_q-I)s_q$ 对任意确定性常色场返回 $c$，即使谱拟合有残差。零强度在实现入口直接返回输入可作为逐位恒等的验收方式。

**反例一：非负输入仍可输出负通道。** 令三条响应列分别是 $(1,.2,.2),(.2,1,.2),(.2,.2,1)$，输入单像素纯红，其他像素为零。未加曲率惩罚的 NNLS 解为 $(25/27,0,0)$。若把有能量的第一波段从原点移走，则原点的渲染值是 **$(2/27,-5/27,-5/27)$**。这正是“非负合成谱＋带符号直通残差”的结果；小的曲率惩罚也不会使严格负余量消失。正性为硬要求时，对可抽取物理光量逐通道限制，使被抽取分量不超过本地非负信号，且使用非负响应/插值；锥外色域允许效果变弱。科学线性母片保留带符号数据，另行定义显示结果的色域处理。

**反例二：保直达项不等于保留全部高频。** 取一个激活、无拟合误差的波段，$c_{\rm hi}=c$，则传递恰为 $1-\gamma+\gamma H$。$H=0,\gamma=0.4$ 的频率输出 **0.6**，而非 1。改验“保护区/未抽取分量恒等，作用区报告频率响应”。对于物理信号同为零的暗区，固定归一核、空间平稳的噪声可使差量的**期望均值**抵消，方差和空间相关仍会改变。两独立点噪声标准差分别为 1、2，取 $s=\max(n,0)$、$K$ 交换二者，第一点输出均值为 $(2-1)/\sqrt{2\pi}=\mathbf{0.39894}$。可用独立低噪先导门控暗部，分别报告均值和噪声功率。

**求积修正。** 用[仓库 Sellmeier 参数](../../../artifacts/hyperchromat-lensbench/run_cuboid_psfs.js#L24)及正文写明的 `435.84 / 656.27 nm`，得材料比 **2.25752**，$\psi_g=0.726764,\ \psi_C=-0.273236$，相对 555 nm 的距离比为 **2.65983**。`2.6607` 对应上一轮使用的 `435.8 / 656.3 nm`，规格固定一组即可。$\kappa=16$ 时 $410..680$ nm 总位移宽 **21.49360 px**。按原式取 36 个等波长区间，即便附加 555 nm 锚点，第一段位移仍有 **1.53718 px**；总宽/段数约束的是平均间距。

在单调色散支上按**位移坐标**划分，并跨全画幅取最大局部位移：此例锚点两侧分别用 **28 与 9 段，含共用锚点共 38 节点**，最大位移间距为 **0.58636 px**。各段积分还须按 $d\lambda$ 或相应 Jacobian 计权，不能把按位移均分误作等波长能量。非单调轨迹按单调支或弧长细分。几何足迹重叠与谱能量是否存在是两项独立条件：以连续白谱细线验采样空档，窄谱源出现无光区应予保留。

### OP-O2｜闭式条带数值成立；匹配半径后要重标物理频率

按提案的圆面积原函数生成每行条带，按平均半弦与像元的交长度分配面积，三个子盘以各自 $\pi r^2$ 归一，再按 `(0.220,0.406,0.374)` 叠加。对中心脉冲直接算带符号的离散余弦响应。下表两行均在**同一个实际频率** $|\omega|=16/32=0.5$ rad/px 取值：

| 传入三圆盘的外半径 | 水平 | 竖直 | 对角 |
|---|---:|---:|---:|
| 32 px，在自己的 $R\lvert\omega\rvert=16$ | **+0.00063305** | **−0.00000097** | **+0.00020640** |
| 匹配旧 Poly2 二阶矩后：$32\times1.14610785=36.67545$ px | **−0.04373166** | **−0.04412951** | **−0.04459741** |

第一行复现 Rev 2。第二行使用同一 UI 指定的旧半径和同一实际频率，新的核自变量已为 **18.3377**。若以新外半径重新规定 `x≤16`，对应物理频带变窄。建议界面/报告分别命名 `R_reference`、`R_kernel`，阈值用 cycles/output-px 表示。在非整数点源中心也应单测：中心偏移 $(0.5,0.5)$、方向 35°、$R=32,\ R|\omega|=16$ 时，扣除中心平移相位后的实部为 **−0.000586**。原提案“中心对齐、三个方向”的 Oracle 仍可保留。

条带总面积是精确积分；用平均半弦作矩形只保整行面积，不保每个像元的圆交面积。单位圆的角像元 $[0.5,1.5]^2$：精确面积 **0.07879**，等效条带给 **0.05709**。条带法依然有工程价值，可用高精度像元面积积分作参考来设误差。现行[原生绘制循环](../heraw_suite_refocus.hpp#L549)仍使用 `rp=r_f+0.5`；本表是对**提议替换核**的独立复算。生产验收应从原生 `render_refocus` 输出同样的脉冲，并测量实际条带内存。

### OP-O3｜频响数字通过；软边处以真实覆盖量检验泄色

$H_s(x)=[2J_1(x)/x]\exp[-(0.45s x)^2/2]$。$s=1$ 时旧峰处 `−0.00915671`，全段最深 `−0.0132186`（$x\simeq4.5118$），对应振幅削弱 14.446× / 10.007×。$s=0.85$ 时旧峰 `−0.0192119`，新的负峰 `−0.0237366`（$x\simeq4.6223$）。这两档现在都有可复现的物理定义。

$G*(mc)/(G*m)$ 对**已知纯背景样本**作归一融合；$m=0$ 的保护输出取原值，局部滤波的这种用法成立。亚像素边缘的拍摄值本身可能已含前景光：白前景、黑背景，边缘样本 $c_1=0.5,\ m_1=0.5$，旁边是真黑背景 $c_2=0,\ m_2=1$。核给二者等权时，背景点得到 **$1/6$**，而真实背景是 0。采用纯背景足迹或已解混的后层，在低支持处回退；保护内逐点相等、整幅斜边 MTF50、双线中心凹陷这三个指标分别验收。

## 4. 建议采纳顺序

1. **接一个真实宿主。** 让同一个 `NijinClient` 通过原生入口打开实拍 burst；核对 Unicode 文件路径、真实活动区和随素材变化的代理图。外部调用者从能力表即可知道有哪些真实 RAW 算子可用。
2. **贯通一个跨切面的公共字段。** 以不同尺寸、旋转后编码的同一 0/1 选区分别走 U8、F32 和 RLE；统一采样后使用原生 S4 算子，按存储不变区和实际作用区分别比较像素。随后对 `attach → 执行 → adopt → 再导出` 验证同名结果和逐阶段缓存。
3. **发布光学验收数据。** 离散三圆盘保留本轮通过的中心脉冲基线；补同物理频率、亚像素中心和部分覆盖边界。连续色散采用最大局部位移间距，De-Nisen 采用已确认的两档强度。三项都能直接在场景线性母片上评价。

达到前两条，就有一条从“任意调用方按接口提交字段”到“宿主使用真实光子、在正确位置生成结果”的验收路径；后续接新工具可以沿用同一契约。
