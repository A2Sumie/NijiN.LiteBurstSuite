# `NijiN.LiteBurstSuite` (`nijinLBS`) 全套件桌面端 UI 与交互定案规格书

> **核心架构定位**：既然项目升级为 **`NijiN.LiteBurstSuite`（多帧连拍全光计算套件）**，UI 必须完整、从容地承载 **`C0–C13` 核心控制、`L1–L10` 全部十类物理场提取、以及 `W1–W14` 全部十四项创意/计量/数据工厂功能**，同时严守三条铁律：
> 1. **宽幅单窗工作台（`1280 × 800 pt`，可自由缩放），日常全流程零模态弹窗**；
> 2. **「首页高频直达 + 四标签深度展开（双向状态同步）」**：在首页（Tab 1）直接保留最高频核心新功能的**快捷开关与语义传送门 `[... ▸]`**——日常 90% 场景（含定格/去路人空镜/慢门流水、基础物理场内嵌、流星瞬态层、降噪直通、查看镜头轨迹入口）**在首页一屏之内零翻页即可闭环**；需要精细调节阈值、开启 2.5D 光场/消反光、勾选 10 类扩展科研场或运行 8× 镜头体检雷达时，点击对应行右侧的 `[... ▸]`（或顶部标签）无缝切入对应专页，且首页与专页共享同一状态源实时同步；
> 3. **物理示能驱动（Affordance-First, Zero Forced-Informative Noise）**：砍除旧版重复的向导按钮/单选、编号徽章与 `(i)` 圆点；用**实测物理量就绪进度条**与**控件因果明暗联动**直接表达可用边界。

### 用户确认后的实施口径

工作台使用宽松可缩放布局；文件/目录选择、另存和引擎选择使用必要对话框，状态与场景推荐在页面内显示。字段选择总数为 **11**，默认启用 motion/phase/focus 三项，导出载体默认独立灰度 PNG。深度显示为相对逆深度；视差仪表统一使用 2× 输出像素。下方线框保留功能位置，实际文案与默认值按本段统一。

## 二、左栏常驻共享底盘（承载导入、静默分簇、`C8` 选相与 `W14` 对焦点审片选片）

无论右侧切换到哪一个工作区，左栏（宽 `460 pt`）始终常驻提供当前数据上下文：
1. **上方「连拍队列」**：
   - **空态即大按钮**：空队列时整块圆角虚线框支持拖放或直接左键点击导入；
   - **拖入即毫秒级静默剖析**：自动渲染连拍组卡片，右上角自动打出传感器特征微标（如 `[Bayer]`、`[X-Trans]`、`[全域 120fps · 已跳帧选8张]`、`[AEB 包围]`）；勾选框 `[✓]` 直接决定该组是否执行（彻底消灭旧版重复的 `[智能向导]` 按钮与 `序列策略` 术语单选）；
   - **非打断式情景胶囊**：仅当某组实测为星空/包围曝光而与右侧当前预设不一致时，卡片内浮现 `[✦ 套用星空]` 小胶囊，一键采纳、绝不弹窗拦截。
2. **中栏快捷操作条**：
   - 除 `[+文件]`、`[+目录]`、`[清空]` 外，直接提供 **`[导出最锐 Top-K 原片...]`（`W14` 独立审片快筛功能）**——哪怕不跑超分合成，摄影师拖入 200 张 `120 fps` 打鸟/运动连拍，也能秒级按真实 `AFPoint` 对焦点主体锐度把最锐的几张原片挑出来拷走！
3. **下方「组内单帧检视台」（内联零弹窗选帧）**：
   - 实时展示当前选中组 `#1..N` 每一帧：左侧复选框 `[✓]` 可手动剔除/强留某张帧；圆点 `●` 一键指定该帧为定格锚点；中间绘制 **AF 对焦点框主体锐度条**（无 AF 框记录时自动回退全图高频锐度）、皇冠 `♛`、位移距离及 `微震 / 动糊 / 黑场` 标记。
