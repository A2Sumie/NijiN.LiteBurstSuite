# 手持光学效果与扩展接口：冻结前审查

**建议冻结通用工具接口：五个切面共用能力发现、字段读写/回注和版本化算子调用。** 支持任意阶张量、标量、表、层级关系及带媒体类型的附件；宿主用语义、单位、坐标和端口连接使用者。掩膜、位移场、光谱核和时间表是互操作测试向量。光学部分以常规手持、同焦点 RAW 连拍为采集前提。

本报告对照[原提案](V3_OPTICAL_LIMITS_AND_SIDECAR_ARCHITECTURE_ZH.md)。[接口指南](../sdk/README_ZH.md)、[Python 会话与算子 SDK](../sdk/nijin_bus.py)、[C11/C++20 字节布局](../sdk/nib_v1.h)是面向接入者的交付入口。

| 决策 | 依据 |
|---|---|
| **可先排期：NIB 文件交换与原生焦外正向平滑** | Python 写出的掩膜/流场可由 C11、C++20 独立读取；已有库的光学核也可逐字节往返。焦外追加非负核稳定，强度和边界可测。 |
| **有条件采用：连续色散与三圆盘 STF** | Sellmeier 色散曲线成立；可呈现的颜色和空间平滑度取决于光谱基与采样。三圆盘的连续解析核很接近带内目标，现有离散圆盘调用在特定方向偏离目标两个数量级。 |
| **固定公共接口：切面、数据和算子** | 宿主发布阶段、字段、算子与端口。共享缓冲传输使用相同逻辑数据契约；精确恢复、似然与近端分别声明状态、目标、精度与版本。 |

## 1. NIB/1：核心与任意调用方的公共契约

### 1.1 公共操作与切面接入示例

| 操作 | 契约 |
|---|---|
| `describe / read` | 取本次 `session`、最后完成的逻辑阶段、可用字段及版本；按名字及行区间取只读张量。字段的名字供查找，`semantic` 和 `unit` 定义其含义。 |
| `write` | 向新包写入一组字段，连同来源帧、目标帧、有效域及坐标变换。生产者写完后发布；一种字段用途对应一种数据语义。 |
| `attach` | 消费者以**当前会话**打开输入包，先校对有序原始帧 ID、参照帧、活动区、几何配置，再校对所请求字段的类型、语义、单位、阶段。错误返回字段名和原因。 |
| `continue` | 接受的字段在下一阶段生效。调用方可完全缺席：同一份 RAW、同一组内核设置，默认路径照常出图。 |
| `describe / call` | 发现算子、输入/输出端口、适用阶段与参数，按版本化名字调用，结果作为同会话字段继续流转。新增工具可调用现有算子，也可发布自有算子。 |

**首发入口一：配准 → 融合。** `S2_ALIGN` 是已完成配准、即将装配融合观测的切面。可输出/输入 `flow.fwd`、`mask.binary` 或有明确标度的软权重。输入流是候选坐标，使用已有配准残差与有效样本检验；缺失时用原生配准。掩膜是选区或路由提示，数值 1 不代表精度无穷大。切面过后换流，应从融合重新计算其下游结果。

**首发入口二：线性成片 → 光学渲染。** `S3_FUSE` 已有带符号的场景线性 RGB，在 `S4_OPTICS` 之前可交入保护选区或已声明尺度的光学核。最简单的实际用途是“对选区以外的焦外做轻微平滑”。RGB 带工作空间、参考曝光、通道次序及预乘语义；光学核带空间单位、像素中心、采样间距、波段、归一化/透过率。系数核的网格与照片的活动区是两套坐标，采用单独的核网格及元数据。

`S1_CALIB` 作为只读测量导出，`S5_DELIVER` 作为结果导出。逻辑阶段名独立于历史 CPU/GPU “Stage 4/5” 编号。建议原生绑定先提供 `export_fields(stage, names, sink)` 和 `attach_fields(stage, bundle) -> accepted/rejected` 两个入口；同一几何方法由 CPU、Metal、Vulkan 使用。下游软件名不进入核心枚举。

### 1.2 字节布局：冻结格式与宿主 `struct` 分开定义

原提案的 `static_assert(sizeof(NibTensorDesc)==128)` 在 Apple Clang/C++20 上**实编失败，实际为 136**；`byte_offset` 在 120，`byte_length` 在 128。`NibBundleHeader` 为 64，但二者自然对齐均为 8。`alignas(64)` 只会填充尺寸，不能把 136 缩成 128。

参考配置保留 64 字节头，把短名改为 40 字节，并明确每项的固定偏移。所有多字节标量为小端，浮点为 IEEE 格式；C 参考直接从字节读取，无须将任意文件地址强转成结构体。全称、层说明可放 UTF-8 manifest。

| 记录 | 偏移与内容 |
|---|---|
| Header 64 B | `0..7` 魔数 `NIJBUS01`；`8,12,16,20,24,28` 六个 `u32` 为版本、阶段、帧数、`active_w/h`、张量数；`32,40,48,56` 四个 `u64` 为会话快速指纹、manifest 偏移/字节数、目录偏移。 |
| Descriptor 128 B | `0..39` ASCII 短名（最多 39 字符，零结尾）；`40,42,44,46` 四个 `u16` 为 dtype、几何类型、来源、codec；`48,52` 为有符号帧/层 ID，`-1` 表示参照域/全局层；`56` 为 `u32 shape[4]`；`72` 为 `f32 affine[6]`；`96` 为 `u32 bbox[4]`；`112,120` 为 `u64` 数据偏移/字节数。 |
| 数据排列 | 头、目录、manifest、各自按 64 B 边界起始的 payload。`codec=0` 连续小端；空间张量用 `[batch,H,W,C]`；`kind=3` 的任意阶张量将实际 `dims,axes` 存在 manifest。空间张量的 `row_bytes=W*C*itemsize`。Python `struct` 格式为 `<8s6I4Q`、`<40s4H2i4I6f4I2Q`。 |
| 元数据 | `session={active_wh,anchor,frames,geometry_id}`；`fields[name]={semantic,unit,…}`；实际需要用到的字段要求语义匹配，其他已知布局的可选字段可跳过。会话身份使用规范化 session（ASCII ID、键排序、紧凑 JSON）之 SHA-256，头内 FNV-1a 64 用于快速分流。 |

同一原文件中的不同 shot、视频帧要有不同 `frames[]` ID。实际生产者应从已识别的 RAW/容器内容、轨道、shot 等构造稳定 ID；`geometry_id` 包含活动区原点/尺寸、CFA 周期和相位、基准帧映射、方向与半像元约定。预览改名无需使文件失效，裁剪原点移动一个像元**必须**使依附该几何的输入失效。`inspect` 用于浏览；接入时调用 `read_index(fp, expected_session)`，比较有序 manifest，返回不匹配的键。状态恢复另有配置/算法身份，见 BUS-O4。

参考实现核对目录跨度、张量字节数、唯一字段名、合法框及每个字段的连续边界，可按行读。明确区分两种存储成本：raw payload 可只读映射；压缩版若以后加入，需提供块目录、原始长度和解压带预算，不能把压缩字节当作连续浮点张量用。共享内存以后可沿用字段，另定义 `request_id / owner / ready / release` 及设备同步；文件 v1 已经能独立完成进程间交换。

**可复现的第一笔交换**（在 `tools/heraw-sr2x` 目录运行；`example` 创建一个新文件）：

```sh
python3 docs/examples/nib_v1.py example demo.nib
python3 docs/examples/nib_v1.py inspect demo.nib
```

示例含 3×2 `region` 掩膜和 `motion` 流：第一行掩膜为 `0,1,0`，位移为 `(1,-2)`。Python 只需 `read_index` 和 `read_rows`；C/C++ 只需[同目录的字段偏移及小端访问器](examples/nib_v1.h)。实际互读得到的偏移为 **704 / 768**，payload 为 **6 / 48 B**。另用项目 [lensbench 的 PSF 库](../../../artifacts/hyperchromat-lensbench/psf_bank_meta.json)中 `spot_sony_150_INF_bare_front_h0` 的 160×160×3 个 FLOAT 做了一次交换，**307200 字节读回一致**。实际接入要保留该库的视场、物距、`halfMm` 和 `T` 等元数据，区分核形状与积分透过率。

### 1.3 坐标、缺测与可消费性（BUS-O1）

定义 `active_1x` 为去活动区偏移后的**传感器原生**像素；轴顺序 `(x,y)`，向右、向下，边界为整数，像素中心为 $(i+1/2,j+1/2)$。矩阵按行存 $x'=a_{00}u+a_{01}v+b_0,\ y'=a_{10}u+a_{11}v+b_1$。2× 输出相应中心在 1× 坐标为 $((i+1/2)/2,(j+1/2)/2)$。避免半像元分歧的办法是让**实际生成网格的调用方导出变换**：例如[原版 SAM](https://github.com/facebookresearch/segment-anything/blob/main/segment_anything/modeling/sam.py)有底/右 padding，而 [SAM2 的一条官方图像路径](https://github.com/facebookresearch/sam2/blob/main/sam2/utils/transforms.py)直接做正方形 resize。同一个名字不能决定预处理。

* **标量与有效域。** 先以 $u=A^{-1}(x-b)$ 判是否落入半开有效边界框。若落在框外，返回 `missing`；若落在框内才把双线性足迹限制到有效像素中心。前者保留真实裁剪的缺测区，后者阻止 padding 参与插值。标签最近邻；概率、logit、辐照度、像元总通量分别声明语义。非矩形缺测区另带 validity 平面。二值掩膜不因放大而变成新的亚像素测量。
* **有限位移。** 源、目标帧的外格到各自活动格的映射为 $T_s,T_t$，则 $v_{\rm act}=T_t(u+v)-T_s(u)$。只有两个网格用**相同**仿射时才退为 $Av$。流字段因此同时声明 `frame, to_frame, affine, to_affine`，位移为像素，速度另需时间单位。局部切向量用 Jacobian；梯度/法向用逆转置；固定位点的向量协方差用 $A\Sigma A^\top$，精度用逆合同。源位置也有误差时，对两端点及其交叉协方差一起传播。
* **WarpGrid。** 存映射方向、结点间距、边界和插值法、有效域；用独立点测最大重投影误差。遮挡断裂处分域，局部折叠处使用有效性和可见性，不能靠加密一张全局光滑网格补出被挡背景。固定分辨率的网格只是近似预算。

**替换 Oracle：** 取 $A=\left(\begin{smallmatrix}0&2\\-3&0\end{smallmatrix}\right)$、外格位移 $(1,2)$。相同两端变换应得 $(4,-3)$；只有目标平移再增 $(10,-4)$ 则应得 **$(14,-7)$**。有效框 $x\in[1,3)$ 时 $x=0.75$ 缺测、$x=1.1$ 在第一有效中心 1.5 取值。用解析线性斜坡和已知位移场验 $10^{-4}$，对独立计算的两个实际光流估计则比较统计误差：估计器本身不必满足旋转/缩放等变。

### 1.4 其余四个总线 Oracle：决定接口语义的边界

| 原 Oracle | 冻结建议与最小反例 |
|---|---|
| **BUS-O2 · 似然与梯度** | 若将来有数值调用方，返回 `loss, grad, objective_id, derivative_kind`，声明单位、颜色基、噪声/可见性是否冻结、归约方式及作用域。线性高斯基准 $L=\|AX-y\|^2/2$ 给 $g=A^\top(AX-y)$；用伴随内积、分层方向差分和绝对＋相对误差验收，再测边缘、各 CFA、Q4/Q5 互斥支持域。`FP64` 参考扫多个步长；导数近零时用绝对误差，整体 FP32 大数相减时用局部损失差。整数提升的代理梯度和真实可微目标分名。`25 ms` 为性能目标：45.7 MP 的 2× RGB32f 输入/梯度合计约 **4.39 GB**，若完整搬运则已需 **175.5 GB/s**；`.cpu().numpy()` 是主机传输路径。报 ROI、帧数、内存驻留、计时范围，微秒级调度另计。 |
| **BUS-O3 · 近端与影响范围** | 若以后开放 `prox`，定义数据项、先验强度、奇异时的规范和终止残差。两像素例 $L=\tfrac12x_1^2+\tfrac12(x_1-x_2)^2$，第二像素无直接测量。添 $50(x_2-1)^2$ 后，解从 $(0,0)$ 变为 **$(100/201,200/201)$**。左侧 $\Lambda_1=0$ 仍受耦合；卷积、重采样和正则均可传播影响。要承诺某 ROI 位级不变，冻结其输出作硬边界；一般情况按算子支持传播来源标签。首发只需记录字段来源与实际使用的阶段。 |
| **BUS-O4 · 恢复与字段交换** | `stage=3` 的图像交换包不是完整检查点。若承诺同后端逐像素一致，保存继续计算需要的未量化状态、全局统计、边界/halo、精度、归约顺序和数值版本，或定义如何从原始输入确定性重算。FLOAT32 值 `1.0002` 经 HALF 恢复为 `1.0`，已足以推翻任意写法都位等的承诺。正例是固定后端/版本、无损完整状态下比较解码后的像素；跨后端给有单位的误差容限。 |
| **BUS-O5 · 会话锁** | 保留对调帧序与改裁剪的负例；增加同尺寸不同活动原点、同 RAW 不同 shot。参考读写器实测调序返回 `session mismatch: frames`，改变几何返回 `session mismatch: geometry_id`。元数据绑定字段身份，归约/求解设置另作 `checkpoint_id`。 |

## 2. 光学一：光谱横向色散与合焦辉光（OP-O1）

**观测条件。** 每像素线性观测为 $c=T s+n$，$T\in\mathbb R^{3\times Q}$ 为积分权与相机响应，$s$ 为谱辐亮度。若 $s$ 是表面反射率，才把假设照明如 D65 乘入 $T$；直接估发光物谱或辐亮度时应使用相应响应。曝光间只有几何变化、相同光谱响应时，更多帧可降噪而不会把三个色通道变成十三个独立光谱测量。理想输出 $Bs=\sum_q t_qK_qs_q$ 对所有可行谱唯一，要求输入零空间中的差异也落在目标零空间。两列 $t_1=t_2$、却有两个不同的位移 $K_1,K_2$ 时，把相同通量放在谱 1 或谱 2，原图相同，输出光纹位置不同。

**七基的真正条件。** 排序分解的系数非负且能重构原 RGB 三个数；要让七个非负**标量物理谱**也精确复色，七个目标顶点必须属于锥 $\{Ts:s\ge0\}$。反例：$T$ 的三列为 $(1,.2,.2),(.2,1,.2),(.2,.2,1)$，任意正谱都有 $G\ge0.2R$，故纯红 $(1,0,0)$ 无解。传感器光谱响应有重叠；换到线性显示 RGB 后，光谱积分列本身还可能带负分量。单纯形分解也不保证它给出的每幅谱是全局最平滑解。将 `c_-` 称作零均值噪声同样不成立：若 $n\sim\mathcal N(0,\sigma^2)$，则 $E[\min(n,0)]=-\sigma/\sqrt{2\pi}$。

**可实施的渲染。** 标定或明确指定响应，离线解带曲率惩罚的非负基谱，并公布各色顶点的复投影误差和适用色域。运行时推荐残差直通的差量形式

$$
c_{\rm render}=c+\sum_q t_q(K_q-I)\,\hat s_q .
$$

收益是：效果关闭时逐值返回输入；均匀场且每个 $K_q1=1$ 时即使拟合残差非零也不偏色。高光选择也可先在源端抽出同一加权场，再做“散出减本地”；保留场景线性 master 及 HDR 负阴影。非负过冲测试在非负输入、非负颜色合成和正权重插值的指定渲染配置上做。带符号的科学输出另测均值、方差及色彩映射。径向缩放还要约定是保表面亮度的拉回还是保积分能量的推送；常量和点源总能量是两种不同的验收量。

**色散数值复算。** 取仓库的 [N-SK16 / N-F2 Sellmeier 系数](../../../artifacts/hyperchromat-lensbench/run_cuboid_psfs.js#L24)。用 435.84/546.07/656.27 nm 的 $|\Delta n_g-\Delta n_e|/|\Delta n_C-\Delta n_e|$ 得 **2.2575**，支持原文的材料数。原文实际渲染以 **555 nm** 为零，分母为 g−C，所得 $\psi(435.8)=0.72683,\ \psi(656.3)=-0.27317$，两端相对锚点距离比却为 **2.6607**。两者都不是最终白线彩色半高宽比；后者还受光源谱、通道响应、原 PSF 和采样影响。不同曲面、非平行入射或另一副玻璃用自己的光线追迹表。

**求积与锐核 Oracle。** 在 $[410,680]$ nm 采用标准 13 点 Gauss–Legendre，中心节点是 **545 nm**。按提案 $\Delta x_q=16\psi(\lambda_q)$，相邻投影位置最大空档为 **3.063 px**；对一像素脉冲作线性插值，全部谱权重为正，剖面仍在整数 $x=4,7,10,13$ 处为零（反向色散时镜像）。因此用窄线/阶跃与高采样参考比较，在给定最小输入带宽下自适应加点或对每谱区间积分；恰需锐核时把 555 nm 设为显式节点并重算权重。一个波段的 $R=0$ 只保该波段的贡献，多色合成 OTF 仍是加权和。产品若要求保留指定比例的清晰主体，应显式保留直达分量或对主体使用恒等门。分带流式组装可以控制内存；每像元至少有 $Q$ 次谱评估/取样，`45 MP <12 ms` 按后端实测，不能用“一个标量面”推出总带宽固定为三分之一。

**采用边界：** 横向色散与 `axial-aura` 可作为场景线性渲染。焦前/焦后全图真实 LoCA 需要有符号离焦及异波段传递证据；共同光学零点和同色异谱示例说明普通手持输入不能为任意背景补出异深单色锐核。全通道截顶时上尾似然给亮度下界，有独立未截顶翼部/曝光才进一步收窄。

## 3. 光学二：现有散景的正向整形（OP-O2、OP-O3）

### OP-O2：三圆盘值得保留，但带内解析值与现有离散实现要分别验收

归一化硬圆盘的带符号 OTF 为 $D(x)=2J_1(x)/x,\ x=R|\omega|$。正权三圆盘 $H_3=\sum_m w_mD(\alpha_m x)$ 保证**空间 PSF 非负且 DC 为 1**；OTF 实部可负，MTF 是其模长。用[实际 STF 系数](../heraw_suite_refocus.hpp#L92)在 `ap=1,sa=0` 做理想连续积分，旧核的 OTF 为 $0.08D(x)+7.36J_2(x)/x^2$。独立 Bessel 数值核对：

| 核与区间 | 带符号 OTF | 对排期的含义 |
|---|---:|---|
| 硬圆盘第一负峰 $x=5.13562$ | −0.1322795 | 可作有符号频响标尺 |

**实际代码入口的反例。** 在 `151×151` 图中央放单位脉冲，常深度 1、焦面 0、`max_radius=64`，关闭口径蚀/多边形/球差，调用 [`render_refocus`](../heraw_suite_refocus.hpp#L246) 的分层圆盘分支，半径依次为 $32(0.28,0.58,1)$，再按 $(0.220,0.406,0.374)$ 加权。按离中心坐标直接算离散 PSF 的归一余弦响应，在 **$x=16$** 得水平 **−0.0159551**、竖直 **−0.0076381**、对角 **−0.0102532**，DC 约 1。这里测的是用现有入口组合三圆盘所得的候选，不是把连续公式采一遍。现有代码作[逐行弦长与像元端点积分](../heraw_suite_refocus.hpp#L551)，几何与理想连续盘不同，尤其影响三个子盘近抵消的频带。

**修正方式。** 先用高精度像元面积积分或适当过采样生成离散参考，按半径/方向比较带内绝对误差、第一零点及点源/阶跃外观，再定权重。要比较“无损替换”，还需匹配尺度：同外半径下，三盘的 $4\,\mathrm{Var}(x_{\rm spatial})/R^2=0.52783$，旧核为 0.69333，低频模糊量不同。行前缀使每条弦的代价近似常量，整圆仍有 $O(R)$ 条弦，[分块前缀](../heraw_suite_refocus.hpp#L639)还可能跨块；三盘是三次圆盘查询，不是半径无关的整核 $O(1)$。从 [12 张矩前缀减少到 4 张](../heraw_suite_refocus.hpp#L374)可省该组 2/3，整体峰值需计入条带、层混合及输出。保留球差正负和口径蚀模式的独立测试。若直接合成环形 PSF，$(1+\eta)P_R-\eta P_{\alpha R}$ 在 $0\le\eta\le\alpha^2/(1-\alpha^2)$ 时空间非负，等号给空心匀环；对已经模糊的未知底片换核则受原核零点限制。

### OP-O3：可削弱二线；旋焦与椭圆拉伸依赖真正作用的区域

实拍背景 $Y=P_R*X+n$，追加 $\sigma=kR$ 的高斯使 OTF 为 $H_{\rm add}(x)=D(x)e^{-(kx)^2/2}$，相同频率的符号和原零点保留。$k=0.45$ 时，在旧负峰 $x=5.1356$ 得 **−0.009157**，该点的反相**振幅**缩小 14.45 倍；乘积的新负峰移到 **$x=4.51177,\ H=-0.013219$**。原文的等效半径 $R\sqrt{1+4k^2}=1.345R$ 是**二阶矩**匹配，高斯尾没有硬半径。滑块 `0.85` 若表示 $k=0.45\times0.85$，原频点振幅只缩小 **6.89 倍**；若用 0.85 线性混合全强度图则约 **4.79 倍**。两条细线的中心凹陷还取决于线间距与整段频谱。

**首版验收：** 锁定强度到 $\sigma/R$ 的映射；频响用正弦输入报固定频点及峰值，视觉用声明线距、对比度、背景半径的双线图测凹陷。主体核心走逐像素恒等，包含保护边界的另一张测试量边缘泄色；用同一层有效支持对模糊的 RGB/coverage 归一，缺背景支持则回退。总提案 E02 是尺度换算问题；仓库的 [`wblur`](../heraw_suite_features.hpp#L1756) 是纹理相关代理，恒定纹理对任何散焦核都能同像。用可辨的点源/边缘、已标定 PSF、已确认的选区估 $\hat R$ 与置信度；低证据处少处理。切向/竖向正向模糊可造定向外观；真实空间变化的瞳形用各自场角核。孤立点源可在圆内检测径向纹理；真实物体细纹和镜片洋葱圈同像时，保持原样或按用户选区处理。

**小光圈虚拟大孔径。** 手持轨迹能提供的瞳宽和其内部采样密度是两个条件。对最高保留频率 $\nu_{\max}$（cycles/px），相邻有效视点对目标深度的残差位移 $\delta d$ 应满足具体角采样的抗混叠条件，例如均匀剪切的单平面有 $\nu_{\max}|\delta d|\le1/2$。同时需覆盖目标瞳面积、具备各层可见性。$\pi(24/1.5)^2=804.25$ 是特定均匀面积近似；常量场一帧即可，共线的千帧也补不出二维角分布。按本次轨迹、光学带宽、视点覆盖给出可合成的孔径，普通手持的首选产品仍是**整形已有散景**。

## 4. 推荐落地顺序

1. **接口 v1：** 将 `S2` 的掩膜/位移和 `S3` 的线性图/渲染选区接到字段读写入口。以本文的 Python→C/C++ 往返、两端坐标不同、裁剪外缺测、交换帧序四例验收；无附加字段时验证原生路径等价。
2. **原生光学：** 优先交付焦外正向平滑及主体保护；三圆盘按实际离散核重新标定，色散按可达色域与工作带宽验证。两项均能用相机线性图、点源和合成图独立验收。
3. **算子和传输接线：** 以 SDK 现有 `describe/call` 协议发布各物理算子的版本、端口与精度；用相同字段描述增加压缩块或共享缓冲。验收看新的调用方能否只靠接口说明发现算子、传入自己命名的数据并读回结果。
